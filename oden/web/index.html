Så räknas tiderna ut

Hook-events har ingen varaktighet, bara tidpunkter. Tider fås genom att para ihop events:

  • Verktygsanrop: duration_ms i PostToolUse/PostToolUseFailure, som inte räknar väntan på tillstånd. Saknas det används tiden från PreToolUse med samma tool_use_id. Anrop utan Post (nekade eller avbrutna) räknas inte.
  • Tur: UserPromptSubmit → Stop. Kommer ett nytt UserPromptSubmit utan Stop emellan avbröts turen (Esc eller nekat tillstånd). Turer som startas av ett klart bakgrundsjobb (<task-notification>) räknas inte som dina prompter.
  • Väntan på tillstånd: PermissionRequest → det verktygets Post minus duration_ms, alltså ungefär när du svarade. PermissionRequest saknar tool_use_id, så det paras med senaste öppna anropet av samma verktyg.
  • Väntar på dig: Stop → nästa UserPromptSubmit från dig.
  • Subagent: SubagentStart → SubagentStop. Interna agenter, som bara skickar SubagentStop, visas inte.
  • Se hook-events.md för vad som gäller för riktiga events.
